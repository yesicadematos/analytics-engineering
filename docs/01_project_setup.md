# 01 - Configuración del entorno

## Objetivo

Configurar el entorno de desarrollo para un proyecto de Analytics Engineering utilizando dbt y Snowflake.

## Herramientas utilizadas

- Git
- GitHub
- VS Code
- Python 3.11
- dbt Core
- dbt-snowflake
- Snowflake

## Actividades realizadas

- Instalación de Python
- Creación del entorno virtual
- Instalación de dbt
- Configuración de Git
- Creación del repositorio
- Configuración de Snowflake
- Configuración del archivo profiles.yml
- Validación de conexión con `dbt debug`
- Creación de la base de datos `AE_DB`
- Creación de los esquemas `RAW`, `STAGING`, `INTERMEDIATE` y `MART`
- Creación del `FILE FORMAT`
- Creación del `STAGE`

## Resultado

- Conexión entre dbt y Snowflake validada.
- Infraestructura inicial lista para comenzar la carga de datos.
